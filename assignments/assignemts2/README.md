## Show Date Button
Displays the output results or the current date from the user when clicked 
 

 you can also press (Alt+S) to display the results

## Clear Button
 Clear button is used to remove the data entered in input controls, such as TextBox.

 you can also press (Alt+C) to Clear the results 

## Exit Button
An Exit button is used to close the application/program.

When the user clicks Exit, the whole application closes.

//
 you can also press (Alt+E) to Close the whole application
