## 2. Course Description

This course introduces students to the principles and practice of programming using the C# programming language. It focuses on developing computational thinking, logical reasoning, and practical programming skills.

Students will learn how to create Windows-based applications using C#, including working with variables, data types, operators, conditional statements, loops, methods, arrays, lists, and files.

The course also introduces database programming using ADO.NET and provides students with practical experience in designing and developing desktop applications through laboratory activities and a final project.

---

## 3. Course Objectives

The main objectives of this course are to enable students to:

- Explain the basic principles of C# programming.
- Develop logical and analytical approaches to solving programming problems.
- Write, test, and debug simple C# programs.
- Understand event-driven programming and Windows Forms.
- Create user-friendly graphical interfaces.
- Apply control structures such as selection and repetition.
- Develop reusable code using methods.
- Store and manipulate collections of data using arrays and lists.
- Perform basic file operations in C#.
- Connect desktop applications to databases using ADO.NET.
- Apply acquired programming knowledge in a practical desktop application.

## 5. Learning Outcomes

At the end of the course, students will be able to:

- Describe the basic concepts of C# and event-driven programming.
- Create simple Windows Forms applications.
- Use variables, constants, data types, and operators appropriately.
- Implement selection and repetition structures in C# programs.
- Design programs using methods and modular programming techniques.
- Use arrays and lists to manage collections of information.
- Perform basic file input and output operations.
- Establish database connections using ADO.NET.
- Retrieve, insert, update, and manage data within a database application.
- Develop, test, and present a functional desktop application.

## 8. Course Project

Students will complete a practical desktop application as the final course project. The project will provide an opportunity to integrate the programming concepts introduced throughout the semester.

The application should include several of the following components:

- Graphical user interface
- Variables and appropriate data types
- Input validation
- Decision-making structures
- Loops
- Methods
- Arrays and/or lists
- File processing
- Database connectivity
- ADO.NET
- Windows Forms
- CRUD operations
- Basic error handling

Students will be expected to demonstrate the functionality of their application and explain the main programming concepts used during the project.
